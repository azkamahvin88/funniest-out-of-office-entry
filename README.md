One line of out-of-office auto-reply, the funniest I could write in 140 characters: the inbox is outsourced to a future self who already resents the decision.

> Out of office until Monday. I've outsourced my inbox to my future self, who hates me now.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
